Proyecto personal Funcional

Hotel Management API

API REST para gestionar usuarios, habitaciones y reservas de un hotel, con autenticación JWT y control por roles.

Problema
Gestionar habitaciones y reservas sin cruces de fechas ni accesos indebidos.
Solución
API por capas con Spring Security, validación de solapamiento de fechas y búsqueda dinámica.

Funcionalidades

  • CRUD de usuarios, habitaciones y reservas con paginación
  • Login con JWT y roles ADMIN / USER
  • Pruebas unitarias, de controlador e integración (JUnit 5, Mockito)
  • Documentación con Swagger y despliegue con Docker
  • Java 17
  • Spring Boot 3
  • Spring Security
  • JWT
  • JPA
  • MySQL
  • Docker
