## ✨ Funcionalidades

- 📱 Diseño **responsive** con menú móvil accesible
- 🎞️ Animaciones al hacer scroll (respetan la preferencia de *menos movimiento*)
- ✉️ Formulario de contacto **funcional** con validación y protección antispam
- 📄 Botón para descargar el CV
- 🔝 Botón para volver arriba y resaltado de la sección actual en el menú
- 🔍 **SEO**: metaetiquetas, Open Graph y datos estructurados
- 🔒 **Seguridad**: Content Security Policy y enlaces externos protegidos
- ♿ **Accesibilidad**: navegación por teclado, contraste AA y etiquetas para lectores de pantalla

## 📂 Estructura

```
├── index.html            # Contenido de todas las secciones
├── 404.html              # Página de error
├── assets/
│   ├── css/styles.css    # Variables → base → componentes → secciones → animaciones
│   ├── js/main.js        # Una función por responsabilidad
│   ├── img/              # Imágenes y favicon
│   └── docs/             # CV en PDF
├── netlify.toml          # Encabezados de seguridad (si se publica en Netlify)
└── robots.txt
```

## 🚀 Ejecutarlo en local

```bash
git clone https://github.com/Gustavobest/PortafolioGustavo.git
cd PortafolioGustavo
python -m http.server 8000
```

Luego abre http://localhost:8000. También funciona con la extensión **Live Server** de VS Code.
